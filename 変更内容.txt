VYSLO MIX チャット修正版（2026-10-04）

このzipのファイルには、下の修正がすでに入っています。

■ 2026-10-05 追加修正その2（夜の踊り子のズレ）
- 原因: フル再生の MV (308秒) の長さに合わせて、歌詞を 306.8秒版 (タイミングが雑な別データ) に
  差し替えていた。さらにその歌詞に自動補正 (+2.1秒) が二重にかかり、2〜3秒遅れていた
- 対処: フル再生中は曲の長さに合う正しい歌詞のまま自動補正で合わせる。
  自動補正できなかったとき・曲の長さが分からないときだけ差し替える (app.js matchDur)
- キャッシュ対策 ?v=2.7.3 / VERSION 2.6.3

■ 2026-10-05 追加修正（歌詞の同期ズレ修正・夜の踊り子など）
※ 再生方法（どの動画をどう流すか）は一切変えていません。歌詞の表示だけを合わせています。

■ 原因
1. フル再生の動画がMV等で長さが元の音源と20秒以上違う場合、歌詞の同期自体が止まっていた
   （canSync() が false になり、自動補正のAPIも呼ばれなかった）
   → 長さが大きく変わる動画で特に顕著だった
2. 複数セグメントのズレ補正で、セグメントの切り替えタイミングがずれることがあった
   （toLyr() の境界判定が toMedia() と一貫していなかった）
3. サーバー側の参照音源検索で、長さの許容値が5秒と厳しく、見つからないことがあった

■ 対応
1. canSync() を「60秒以上再生していること」だけに簡略化（長さの差で止めない）
   → 長さが違っても自動補正が走るようになった
2. toLyr() を修正: 現在のラグで一旦変換してから次セグメントの境界を判定する方式に変更
   → toMedia() と一貫した正しいセグメント選択
3. lyralign.py の _find_ref() で参照音源の長さ許容値を 5秒→10秒 に緩和
4. index.html のキャッシュバージョンを ?v=2.7.1 → ?v=2.7.2 に更新

==============================
VYSLO-MUSIC 音量調整・歌詞の同期ズレ修正
==============================
※ 音楽の再生方法（フル再生・Spotify埋め込み・試聴の選び方や流し方）は一切変えていません。

■ 音量
1. 音量スライダーを常に表示（前は Spotify 埋め込み再生中や、幅1100px以下・スマホでは隠れていた）
2. 狭い画面・スマホでは、プレーヤーのスピーカーボタンを押すと音量ポップアップが開く
3. PC ではスピーカーボタンでミュート/解除。キーボードは M でミュート、Shift+↑/↓ で 5% ずつ
4. スライダー上でマウスホイールでも調整できる
5. 音量とミュートは保存され、ページを開き直しても同じ音量で鳴る（前は再読み込み直後の表示がずれていた）
6. Spotify 埋め込み再生中も、同じドメイン経由で読み込めている場合は音量を反映
7. iPhone/iPad はブラウザから音量を変えられない仕様のため、本体ボタンで調整するよう案内を表示

■ 歌詞の同期
1. 再生位置を timeupdate（約0.25秒ごと）や Spotify の通知（約1秒ごと）待ちではなく、画面の更新ごとに直接読み取るように変更（遅れ・カクつきの解消）
2. 流れている音源の長さと歌詞データの長さが2.5秒以上違うときは、その長さに合う版の歌詞を探し直す
3. 歌詞パネルに「歌詞のタイミング」調整（−0.5秒 / +0.5秒 / リセット）を追加。曲ごとに保存される
4. 歌詞の行をクリックしたときのシークも調整値を反映
5. LRC の [offset:] タグを反映

==============================
VYSLO-MUSIC 歌詞のズレ 自動補正（追加修正）
==============================
※ 再生方法（どの動画をどう流すか）は変えていません。歌詞の表示だけを合わせています。

■ 原因
フル再生では MV など、前奏や効果音が足された動画が流れることがある。
歌詞データ（LRCLIB）は元の音源の時間で書かれているため、数秒ずれていた。
例: マカロニえんぴつ「恋人ごっこ」の MV は元の音源より約5.7秒遅い → 歌詞が約5.7秒早く進んでいた。

■ 対応
1. 新しい API /api/lyrics/align を追加（apps/music/lyralign.py）
   - 歌詞と同じ長さの「元の音源」（YouTube Music の公式音源）を探す
   - 再生中の動画と元の音源の音声をサーバーでデコードし、音の立ち上がりを比べてズレを測る（10秒区間ごと）
   - 結果は 7日間キャッシュ
2. 歌詞パネルが自動でこのズレを反映（「自動補正 +5.7秒」と表示）。手動のタイミング調整はその上に足される
3. 必要ライブラリ: numpy, av（apps/music/requirements.txt に追加）

■ 変更したファイル
- apps/music/lyralign.py（新規）
- apps/music/main.py
- apps/music/requirements.txt
- apps/music/static/js/player.js / app.js / css/app.css / index.html（?v=2.7.1）
